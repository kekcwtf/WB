# Первый запуск WB Profit Desktop на Windows

## Установка

1. Скачайте `WB-Profit-Desktop-Setup.exe` из результата Windows-сборки этого репозитория.
2. Откройте установщик двойным щелчком. Python и PowerShell устанавливать или запускать не требуется.
3. После установки откройте ярлык **WB Profit Desktop** на рабочем столе.

Приложение предназначено для Windows 11 x64. Автоматические проверки на Windows runner не заменяют проверку на вашем компьютере. Цифровая подпись установщика пока не настроена; Windows может показать предупреждение о неизвестном издателе.

## Подключение магазина

1. В настройках добавьте магазин с понятным вам названием.
2. Создайте токен в кабинете продавца Wildberries. Для используемых источников нужны категории **Финансы**, **Статистика**, **Аналитика**, **Контент** и **Продвижение**. Программа получает данные через официальный API и не меняет заказы, карточки или рекламу.
3. Нажмите **Сохранить токен в Windows Credential Manager** и вставьте токен в поле приложения. Не отправляйте токен в чат, письмо или репозиторий.
4. Нажмите **Обновить сейчас**. Программа сначала проверит продавца, затем начнёт загрузку. Токен другого продавца не должен смешиваться с прежним магазином — добавьте для него отдельный магазин.

Для контрольных сумм финансовых отчётов нужен персональный или сервисный токен. Базовый токен имеет дополнительные ограничения методов и частоты. При первом запуске история может загружаться долго: ограничения WB сохраняются даже при ручном обновлении. Состояние каждого источника видно в «Обзоре».

## Себестоимость и налоги

Закупочная себестоимость не поступает из WB API. В «Товарах» нажмите **Проверить себестоимость за выбранный период**, выберите точный SKU/баркод и перенесите его в настройки. Введите свою цену закупки с правильной датой начала действия и сохраните. Другие размеры автоматически не получают эту цену. Общая цена применяется только после явного назначения отдельной кнопкой.

Налоговые ставки и даты задайте по своей системе налогообложения. Значения 940 ₽, УСН 4% и НДС 5% — примеры, а не автоматически назначенные настройки. Подтверждение параметров означает ваше согласие с моделью расчёта, а не подтверждение налогового обязательства. НДС, уже включённый в цену, выделяется из цены.

Ошибочную версию цены или налогов можно исправить либо удалить; последние изменения доступны для отмены и сохраняются в журнале. Внешние расходы вводятся вручную только для затрат вне WB. Ошибочный внешний расход можно отменить и восстановить.

## Как читать результат

- **Недостаточно данных** не означает нулевую прибыль или убыток.
- Продажи и возвраты оперативной статистики не заменяют закрытые финансовые отчёты.
- Покрытие дат загрузки не означает, что денежные суммы сверены.
- Смотрите «Сверку»: неизвестные операции, корректировки и расхождения требуют разбора.
- Расход без SKU может относиться ко всему магазину. Он учитывается в результате магазина даже без распределения на товары.
- Расчётная прибыль при несопоставленной рекламе и налоговом эффекте возвратов остаётся недоступной. Программа не скрывает эти ограничения и не подменяет их оценкой.

До использования для ежедневных решений нужно проверить данные реального магазина и сопоставить результат с финансовым отчётом WB. Подробный список ограничений — в [STATUS.md](STATUS.md).

## Данные и обновление

База находится в пользовательской папке данных Windows отдельно от программы. Обновление установщиком не должно удалять эту базу. Резервные копии создаются, пока программа открыта; копии на том же диске не защищают от его отказа. Папку копий можно открыть из настроек и скопировать на другой носитель.

Токены хранятся отдельно в Windows Credential Manager и в копию SQLite не входят. После переноса на другой компьютер токен нужно сохранить в приложении заново. При восстановлении базы на том же компьютере сохранённые токены не удаляются.
